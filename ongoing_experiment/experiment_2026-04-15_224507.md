## Interpretation

This is the first serious retraining run after upgrading the host architecture and training loop. It completed cleanly and is clearly stronger than the old host. One important nuance is that the checkpoint minimizing the total validation loss is not the same as the final epoch with the strongest RMSE/PCC. If we follow the training objective strictly, epoch `42` is the selected checkpoint; if we optimize only for frame metrics, later epochs look stronger.
